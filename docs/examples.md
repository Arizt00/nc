# Examples

Examples are grouped by topic instead of historical internal labels. Historical
or oversized fixtures live under `_archive/old_examples`; the active example
tree keeps the clean level layout below.

| Group | Public area | Purpose |
| --- | --- | --- |
| `00_hello` | Hello | First run and print |
| `01_basics` | Basics | Variables, arithmetic and render |
| `02_flow` | Flow | Conditions, loops and counters |
| `03_types` | Types | `type`, `stc`, `local` and records |
| `04_arrays` | Arrays | Fixed arrays and indexed access |
| `05_lists` | Lists | Dynamic lists and list access |
| `06_memory` | Memory | Pointers, heap and regions |
| `07_runtime` | Runtime | IO, FS and runtime imports |
| `08_project` | Project | Multi-file project bridge |
| `09_ffi` | FFI | Foreign function interfaces |
| `10_mct` | MCT | Byte-contract examples |
| `11_machine` | Machine | `[@machine]` and object formats |
| `12_primitive` | Primitive ISA | Cross-ISA basal and material contracts |
| `primitive` | Primitive hardware | `primitive[@]`, material targets and hardware workflows |
| `99_stress` | Stress | Stress and parity fixtures |
