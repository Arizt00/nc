# Machine Symbol Resolution

Phase 12 link reports distinguish resolved symbols, unresolved symbols, duplicate symbols, entry point resolution, visibility policy, and import/export lists.

Unresolved and duplicate symbols are diagnostics, not silent outcomes. The official diagnostics include `E_MACHINE_LINK_UNRESOLVED_SYMBOL_001`, `E_MACHINE_LINK_DUPLICATE_SYMBOL_001`, and `E_MACHINE_LINK_ENTRY_MISSING_001`.
