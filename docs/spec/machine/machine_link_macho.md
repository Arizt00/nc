# Machine Link Mach-O

Mach-O profile integration is closed for `x86_64-apple-darwin` machine artifacts. The profile covers executable artifacts, static library archives, relocation reports, and compact-unwind or DWARF fallback preservation metadata.

For executable phase12 artifacts, `machine link` and `machine build-exe` now emit an OS-loader executable (`MH_EXECUTE`) with page-aligned `LC_SEGMENT_64` commands, `LC_MAIN`, `LC_BUILD_VERSION`, `LC_SYMTAB`, `LC_DYSYMTAB`, and `LC_CODE_SIGNATURE`. The in-process final linker consumes phase12 `link_unit` metadata when present, or imports third-party Mach-O relocatable objects directly from `LC_SEGMENT_64`, `LC_SYMTAB`, `nlist_64`, and section relocation entries. It merges `__TEXT,__text`, `__TEXT,__const`, `__DATA,__data`, `__DATA,__bss`, resolves cross-object symbols, respects the declared entry symbol, writes native `nlist_64`/string-table records for defined and imported symbols, and applies final `X86_64_RELOC_BRANCH`/`X86_64_RELOC_UNSIGNED` relocations as `rel32`/`abs64`. Dynamic-import artifacts additionally materialize dyld load commands such as `LC_LOAD_DYLINKER`, `LC_LOAD_DYLIB`, `LC_DYLD_INFO_ONLY`, and `LC_DYSYMTAB`; `__LINKEDIT` carries bind/lazy-bind streams, indirect-symbol metadata, symbol/string tables, and an ad-hoc SHA-256 CodeDirectory SuperBlob. The contract is documented in [Machine Dynamic Unix Imports](machine_link_dynamic_unix.md). `NCCLINK12` remains the deterministic internal lane for non-final artifact shapes and unsupported executable writer targets.

The final Mach-O smoke is `ncc machine link-smoke examples/machine/native/link_final_macho_exit42.nm --target x86_64-apple-darwin --system-loader --expect-exit 42 --json`. It must execute on a native macOS x86_64 runner; non-macOS hosts report a typed blocked state rather than counting object bytes as execution.

Producer-side Mach-O compatibility is part of `ncc machine third-party-objects --json`. The macOS clang row generates real Mach-O relocatable objects and checks branch plus unsigned absolute relocation import before final Mach-O byte emission.
