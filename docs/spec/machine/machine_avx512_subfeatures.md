# Machine AVX-512 Subfeatures

Tracked subfeatures are AVX512F, AVX512DQ, AVX512BW, AVX512VL, AVX512CD, AVX512IFMA, AVX512VBMI, AVX512VNNI, AVX512BITALG, AVX512VPOPCNTDQ, and AVX512FP16.

AVX512F has a closed Phase 4A foundation. DQ, BW, VL, CD, IFMA, VBMI, VNNI, BITALG, VPOPCNTDQ, and FP16 remain deferred to later Phase 4 subphases with explicit diagnostics.
