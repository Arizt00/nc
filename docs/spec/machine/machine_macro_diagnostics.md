# Machine Macro Diagnostics

Phase 10 macro diagnostics are official:

- `E_MACHINE_MACRO_DECL_001`
- `E_MACHINE_MACRO_PARAM_001`
- `E_MACHINE_MACRO_ARG_001`
- `E_MACHINE_MACRO_VARIADIC_001`
- `E_MACHINE_MACRO_RECURSION_001`
- `E_MACHINE_MACRO_EXPANSION_001`
- `E_MACHINE_MACRO_LABEL_COLLISION_001`
- `E_MACHINE_MACRO_UNRESOLVED_LABEL_001`
- `E_MACHINE_MACRO_HYGIENE_001`

Each diagnostic is surfaced by `machine check`, represented in JSON reports, and covered by a negative example.
