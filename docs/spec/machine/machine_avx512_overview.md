# Machine AVX-512 Overview

AVX-512 in `[@machine]` is built on the closed EVEX encoding layer. Phase 4A creates the AVX-512 manifest, subfeature matrix, operand-form matrix, feature gates, and the first closed AVX512F foundation carriers.

Phase 4A does not close AVX-512 total. Family closure remains split across Phase 4B, Phase 4C, Phase 4D, Phase 4E, and Phase 4F.
