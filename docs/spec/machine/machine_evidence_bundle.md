# Machine Evidence Bundle

The Phase 9 evidence bundle is rooted at `reports/machine_native_total/evidence_bundle`.

It references:

- Final machine and native doctor reports.
- Cross-arch doctor and parity reports.
- Phase closure reports for VEX, AVX2, EVEX, AVX-512, debug/unwind, disasm, roundtrip, and cross-arch parity.
- Conformance and regression matrices.
- Positive and negative example matrices.
- Known limitations.
- Worktree debt report.

If reports are not versioned in a downstream checkout, regenerate the bundle with the validation commands listed in `reports/machine_native_total/phase9/phase9_release_readiness.md`.
