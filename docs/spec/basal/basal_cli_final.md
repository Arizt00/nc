# Basal Final CLI Matrix

The final Basal CLI surface is governed by the terminal. IDE integrations may
assist, but the CLI remains the release authority.

Closed commands:

- `ncc basal check`
- `ncc basal parse`
- `ncc basal ast`
- `ncc basal tables`
- `ncc basal ir`
- `ncc basal verify-ir`
- `ncc basal lower`
- `ncc basal verify-lowering`
- `ncc basal surface`
- `ncc basal verify-surface`
- `ncc basal report-plan`
- `ncc basal emit-nbb`
- `ncc basal verify-nbb`
- `ncc basal read-nbb`
- `ncc basal inspect-nbb`
- `ncc basal nbb-info`
- `ncc basal evidence`
- `ncc basal integrate-evidence`
- `ncc basal seal`
- `ncc basal verify-seal`
- `ncc basal evidence-report`
- `ncc basal seal-report`
- `ncc basal report`
- `ncc basal read`
- `ncc basal doctor`
- `ncc basal doctor --json`

The generated Phase 7 CLI matrix records a smoke command and pass/fail status
for each command.
