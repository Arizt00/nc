# Basal Known Limitations

Basal is release-sealed for the declared Phase 1 through Phase 7 scope. The
following remain outside this closure:

- new high-level language features
- runtime behavior changes
- primitive layer changes
- non-declared machine target expansion
- release packaging outside the generated evidence bundle
- repository cleanup beyond classification and commit planning

Basal Phase 7 does not claim the worktree is clean. It claims the worktree is
classified and that remaining debt is visible for review.
