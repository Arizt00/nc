# Basal Seal Hash Chain

Phase 6 records a hash chain that ties source lowering to machine validation:

1. Basal lowering plan hash.
2. Executable surface hash.
3. Machine doctor hash.
4. Native doctor hash.
5. Emitted object byte hash.
6. Verify-object report hash.
7. Disasm report hash.
8. Roundtrip report hash.
9. Evidence hash.
10. Final seal hash.

Any changed NBB byte must be caught by the structural checksum before the seal verifier accepts the artifact.
