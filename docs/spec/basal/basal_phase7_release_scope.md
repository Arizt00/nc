# Basal Phase 7 Release Scope

Basal Phase 7 is limited to release seal, conformance, evidence bundle, and
worktree classification.

Allowed work:

- final status docs
- final reports
- evidence bundle manifest
- conformance matrix
- release notes
- commit and packaging plan
- no-regression tests for the final doctor gate

Forbidden work:

- new language features
- semantic changes to Basal Phases 1 through 6
- NBB0 semantic changes
- machine semantic changes
- high-level/runtime/primitive changes
- deleting inherited worktree debt without review

Basal Phase 7 closes the release-readiness record. It does not pretend the
repository has no unrelated dirty files.
