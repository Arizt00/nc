# Import Diagnostics

Baseical diagnostics:

- `E_USE_DOMAIN_UNKNOWN_001`
- `E_USE_FAMILY_UNKNOWN_001`
- `E_USE_ITEM_UNKNOWN_001`
- `E_USE_STOUD_AUTH_REQUIRED_001`
- `E_USE_AUTH_REQUIRED_001`
- `E_USE_AUTH_MODE_FORBIDDEN_001`
- `E_USE_MODE_FORBIDDEN_001`
- `E_USE_FORBIDDEN_IN_MACHINE_001`
- `E_USE_FORBIDDEN_IN_PRIMITIVE_001`
- `E_USE_FORBIDDEN_IN_BASAL_001`
- `E_USE_FORBIDDEN_IN_KERNEL_001`
- `E_USE_EXPANSION_UNKNOWN_001`
- `E_USE_ALIAS_AMBIGUOUS_001`
- `E_USE_WILDCARD_DENIED_001`

Unknown domains, families or items fail explicitly. Unknown imports are never accepted silently.
