# ghor Lockfile

The official lockfile generated by ghor is `ghor.lock`.

The current lockfile schema is `ghor.lock.v1` and records:

- lockfile version;
- generator version;
- package name, version, and manifest hash;
- target and profile;
- mode capabilities;
- native language and foreign adapter metadata;
- resolved dependencies;
- dependency source, version, checksum, and local path where applicable.

`ghor verify-lock` recomputes the lock from `nc.toml` and reports `E_GHOR_LOCK_DRIFT_001` when the file does not match the manifest resolution.

Remote dependencies without checksums are rejected with `E_GHOR_CHECKSUM_001`.
