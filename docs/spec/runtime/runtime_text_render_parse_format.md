# Runtime Text Render Parse Format

## Text/String
Transformación y lectura de texto bajo reglas runtime.

## Parse
Conversión segura/estricta (`parseInt`, `parseFloat`, etc.) con diagnóstico.

## Render/Format
Salida estable de tipos numéricos y estructurados.

## Regla
Sin capability/policy asociada, la operación falla con código canónico.
