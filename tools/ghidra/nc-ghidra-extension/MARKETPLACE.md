# Marketplace publication guide — nC Ghidra Extension

## Extension name

nC Ghidra Extension

## Short description

Ghidra integration for nC low-level artifacts and reports generated by ncc.

## Long description

nC Ghidra Extension provides low-level analysis integration for nC artifact workflows. It is designed to consume ncc outputs and reports for machine/primitive-facing analysis contexts. It does not replace ncc and does not invent disassembly or semantic authority.

If the ncc machine surface is partial/deferred, the extension remains constrained to available official routes (`emit-backend`, `emit-object`, `emit-elf`) and report-driven analysis.
